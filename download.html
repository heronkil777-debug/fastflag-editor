Por que FastFlag Editor?

Ferramenta completa para gerenciar FastFlags do Roblox com interface moderna e recursos avançados.

CRUD Completo

Crie, edite, duplique e delete FastFlags. Valores, nomes, tags e presets — tudo editável inline.

Sistema de Tags & Presets

Organize com tags personalizadas, auto-tag inteligente por nome e presets para ativar/desativar em lote.

Import/Export Universal

JSON nativo, formato Roblox (ClientAppSettings) e exportação própria com metadados. Drag & drop para importar.

Undo/Redo Ilimitado

Histórico completo com zundo. Desfaça qualquer alteração com Ctrl+Z / Ctrl+Y.

Segurança Total

contextIsolation: true, nodeIntegration: false. IPC tipado e validado com Zod.

Auto-Update via GitHub

Verifica atualizações automaticamente no startup. Notifica quando nova versão disponível e instala com um clique.

Interface

Tema escuro elegante, tabelas responsivas, menus contextuais e wallpaper personalizável.
